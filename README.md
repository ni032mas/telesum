# Telesum — Telegram Chat Summary

Веб-приложение для суммаризации Telegram-чатов. Собирает сообщения за последние N часов и генерирует краткое саммари с помощью AI (Claude, Gemini или Qwen).

Всё управляется через удобный веб-интерфейс — не нужно редактировать файлы или работать в терминале после начальной установки.

---

## Что нужно перед началом

1. **Node.js 18+** — среда для запуска JavaScript-приложений
2. **CLI для LLM** — программа, которая будет делать саммари (одна из трёх):
   - [Claude Code](https://claude.ai/code) (`claude` в терминале)
   - [Gemini CLI](https://github.com/google-gemini/gemini-cli) (`gemini` в терминале)
   - [Qwen CLI](https://github.com/QwenLM/qwen-cli) (`qwen` в терминале)
3. **Telegram-аккаунт** с номером телефона

> **Что такое Node.js?** Это программа, которая позволяет запускать JavaScript-код на компьютере (а не только в браузере). Telesum написан на JavaScript/TypeScript, поэтому без Node.js он не запустится. Вместе с Node.js устанавливается `npm` — менеджер пакетов, который скачивает нужные библиотеки.
>
> **Что такое LLM CLI?** Это программа командной строки, которая отправляет текст на AI-модель и получает ответ. Telesum использует её «под капотом» — вы просто нажимаете кнопку в интерфейсе, а программа сама вызывает нужную CLI.

## Шаг 1. Установи Node.js

Если у тебя уже есть Node.js 18+, пропусти этот шаг. Проверь:

```bash
node -v
```

Если команда выдаёт `v18.0.0` или выше — всё ок. Если нет:

### macOS

**Вариант A — Установщик (проще всего):**

1. Открой [nodejs.org](https://nodejs.org/)
2. Скачай версию **LTS** (кнопка слева)
3. Запусти скачанный `.pkg` файл
4. Следуй инструкциям установщика

**Вариант B — Через Homebrew** (если он установлен):

```bash
brew install node
```

### Windows

1. Открой [nodejs.org](https://nodejs.org/)
2. Скачай версию **LTS** (кнопка слева)
3. Запусти скачанный `.msi` файл
4. Следуй инструкциям, оставь все галочки по умолчанию
5. **Перезапусти терминал** после установки

### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# Или через nvm (рекомендуется):
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
nvm install 22
```

После установки проверь:

```bash
node -v   # должно показать v18+ или v22+
npm -v    # должно показать 9+ или 10+
```

## Шаг 2. Установи LLM CLI

Тебе нужна хотя бы одна из этих программ. Она будет генерировать саммари из сообщений.

### Claude Code (рекомендуется)

```bash
npm install -g @anthropic-ai/claude-code
```

После установки авторизуйся:

```bash
claude
```

Откроется браузер — залогинься в свой аккаунт Anthropic. API-ключ не нужен.

Проверь: `claude --version`

### Gemini CLI

```bash
npm install -g @google/gemini-cli
```

Для Gemini нужен API-ключ:

1. Открой [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Нажми **Create API Key** (бесплатно)
3. Скопируй ключ

Ключ нужно будет добавить в переменные окружения:

```bash
# macOS/Linux — добавь в ~/.zshrc или ~/.bashrc:
export GEMINI_API_KEY=твой_ключ

# Windows PowerShell:
$env:GEMINI_API_KEY="твой_ключ"
```

Проверь: `gemini --version`

### Qwen CLI

```bash
npm install -g qwen-cli
```

После установки авторизуйся:

```bash
qwen auth
```

Следуй инструкциям. API-ключ не нужен.

Проверь: `qwen --version`

## Шаг 3. Получи API-ключи Telegram

Эти ключи нужны, чтобы приложение могло подключиться к Telegram от твоего имени и прочитать сообщения из чатов.

### 3.1. API ID и API Hash

1. Открой [my.telegram.org](https://my.telegram.org) в браузере
2. Введи свой номер телефона (с кодом страны, например `+79001234567`)
3. Введи код, который придёт в Telegram
4. Нажми **API development tools**
5. Заполни форму (можно написать что угодно):
   - **App title:** `My Summary App`
   - **Short name:** `summary`
   - **Platform:** можно оставить по умолчанию
6. Нажми **Create application**
7. Запиши **App api_id** (число) и **App api_hash** (длинная строка)

> **Важно:** создать приложение можно только из страны, где зарегистрирован номер телефона.

### 3.2. Узнай ID чатов-источников

Это чаты, из которых будут собираться сообщения. Можно указать несколько через запятую.

**Если чат публичный** (есть ссылка вида `t.me/channel_name`):

Просто используй имя без `t.me/`. Например, для `t.me/dev_talks` пиши `dev_talks`.

**Если чат приватный:**

1. Открой [web.telegram.org/a](https://web.telegram.org/a/) в браузере
2. Перейди в нужный чат
3. Посмотри на адресную строку — там будет число, например `#-5136087299`
4. Это и есть ID чата: `-5136087299`

## Шаг 4. Скачай и запусти Telesum

### 4.1. Открой терминал

- **macOS:** Cmd + Пробел → набери `Terminal` → Enter
- **Windows:** Win + R → набери `cmd` → Enter (или найди PowerShell в меню)
- **Linux:** Ctrl + Alt + T

### 4.2. Скачай проект

```bash
git clone https://github.com/ni032mas/telesum.git
cd telesum
```

> Если у тебя нет `git`, можно скачать ZIP-архив с GitHub и распаковать.

### 4.3. Запусти

**Быстрый старт (одна команда):**

```bash
./start.sh
```

Скрипт сам установит зависимости, соберёт проект, запустит сервер и откроет браузер.

> На Windows используй: `bash start.sh` (если установлен Git Bash) или выполни шаги вручную (см. ниже).

**Ручной запуск:**

```bash
npm install       # установка зависимостей (первый раз)
npm run build     # сборка проекта
npm start         # запуск сервера
```

После запуска открой в браузере: **http://localhost:3001**

## Шаг 5. Настрой через веб-интерфейс

После запуска откроется веб-приложение. Все дальнейшие настройки делаются в нём — не нужно редактировать файлы вручную.

### 5.1. Settings (Настройки)

Перейди в раздел **Settings** и заполни:

- **API ID** и **API Hash** — из шага 3.1
- **Source Chats** — ID или username чатов через запятую (из шага 3.2)
- **LLM CLI** — какую программу использовать (`claude`, `gemini` или `qwen`)
- **Model** — модель для выбранного CLI (например `sonnet` для Claude, `gemini-2.5-flash` для Gemini)

Нажми **Save Configuration**.

### 5.2. Auth (Авторизация в Telegram)

Перейди в раздел **Auth**:

1. Введи свой номер телефона (с кодом страны: `+79001234567`)
2. Нажми **Send Code**
3. Введи код, который придёт в Telegram
4. Если у тебя двухфакторная аутентификация — введи облачный пароль

Авторизация выполняется один раз. Сессия сохраняется автоматически.

### 5.3. Dashboard (Панель управления)

Перейди в раздел **Dashboard**:

- Увидишь список подключённых чатов
- Нажми **Run Now** — запустится сбор сообщений и суммаризация
- Прогресс отображается в реальном времени

### 5.4. Summaries (История)

В разделе **Summaries** хранятся все сгенерированные саммари. Можно просматривать и удалять.

## Настройка промпта

Промпт для суммаризации можно редактировать прямо в веб-интерфейсе (раздел **Settings**, блок **Prompt Template**). Есть кнопка «Reset to default» для возврата к стандартному промпту.

Доступные плейсхолдеры:
- `{messages}` — сюда подставляются сообщения из чатов
- `{hours}` — количество часов (`HOURS_BACK`)

## Опциональные настройки

### Отправка саммари в группы (через userbot)

Если хочешь, чтобы саммари автоматически отправлялось в группы:

1. Узнай ID группы (см. шаг 3.2)
2. В **Settings** заполни поле **Destination Chats** (через запятую)
3. Ты должен быть **участником** этих групп

### Отправка через бота

Альтернативный способ — отправка через Telegram-бота:

1. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен
2. В **Settings** заполни:
   - **Bot Token** — токен бота
   - **Destination User ID** — твой Telegram ID (узнай через [@userinfobot](https://t.me/userinfobot))

## Частые проблемы

### `node: command not found`

Node.js не установлен или не добавлен в PATH. Установи его по инструкции в шаге 1. После установки **перезапусти терминал**.

### `npm install` выдаёт ошибку с правами доступа

```bash
# macOS/Linux:
sudo rm -rf ~/.npm/_cacache
npm install
```

### `claude/gemini/qwen: command not found`

LLM CLI не установлен. Установи по инструкции в шаге 2 и проверь:

```bash
claude --version   # или gemini --version, или qwen --version
```

Если установил, но команда не найдена — перезапусти терминал.

### `Could not find the input entity` при суммаризации

- Для **публичных** чатов используй username (например `dev_talks`), а не числовой ID
- Для **приватных** чатов убедись, что ты участник, и бери ID из адресной строки [web.telegram.org](https://web.telegram.org/a/)

### Порт 3001 уже занят

Другая программа использует этот порт. Найди и останови её:

```bash
# macOS/Linux:
lsof -i :3001
kill -9 <PID>
```

### Саммари пустое или с ошибкой

- Убедись, что в чате есть сообщения за указанный период (`HOURS_BACK`)
- Проверь, что LLM CLI работает: `echo "Hello" | claude --print` (или `gemini`, `qwen`)
